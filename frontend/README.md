# Gaming Hub

Gaming Hub is a desktop launcher inspired by Steam, Netflix and Playnite.
The project is in initial state of development

## Current Technologies

- React
- TypeScript
- Vite

## Current Features

- Game Library
- Game Cards
- Platform Sections
- Search Bar (UI)

## Roadmap

- Search System
- Emulator Integration
- SQLite Database
- FastAPI Backend
- Desktop Version
